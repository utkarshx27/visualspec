# The Visual Spec Contract

The **Visual Spec** is the core contract between user intent, layout templates, AI model adapters, and deterministic renderers.

## Top-Level Schema

```yaml
version: "0.1"

asset:
  id: string              # Unique identifier
  platform: string        # e.g., 'instagram', 'linkedin', 'generic-social'
  type: string            # e.g., 'product_launch', 'quote_card', 'stat_card'
  template: string        # Template ID from templates/
  format: string          # e.g., 'feed_portrait', 'square', 'story'

canvas:
  width: integer          # e.g., 1080
  height: integer         # e.g., 1350
  aspect_ratio: string    # e.g., '4:5'

intent:
  objective: string       # Core communication objective
  audience: string        # Target audience
  message: string         # Core message
  mood: list[string]      # e.g., ['premium', 'futuristic', 'minimal']

brand:
  palette:
    primary: string       # Hex code (e.g., '#6C5CE7')
    secondary: string     # Hex code (e.g., '#00D2FF')
    background: string    # Hex code (e.g., '#09090B')
    text: string          # Hex code (e.g., '#FFFFFF')

subject:
  description: string     # Description of core physical/3D subject
  placement: string       # e.g., 'lower_center', 'center'
  prominence: float       # 0.0 to 1.0

background:
  description: string     # Description of background environment
  texture: string         # e.g., 'subtle_grain'

composition:
  hierarchy: list[string] # Priority order of elements
  focal_point: string     # Primary focal point
  negative_space:
    target: string        # Region reserved for clean text readability

text:
  <slot_name>:
    content: string       # Exact text content
    exact: boolean        # If true, text must match verbatim
    max_lines: integer    # Allowed line wrap budget
    placement: string     # Region (e.g., 'upper_third', 'center')
    alignment: string     # 'left', 'center', 'right'
    typography:
      family_class: string# 'grotesk', 'geometric', 'serif', 'mono'
      weight: integer     # 300, 400, 500, 600, 700, 800, 900
      scale: string       # 'xs', 'sm', 'md', 'lg', 'xl', '2xl', '3xl'
      color: string       # Hex color or brand reference

constraints:
  required: list[string] # Mandatory slots
  forbid: list[string]   # Forbidden visual artifacts
  exact: list[string]    # Invariant text fields

generation:
  image_layers: list[string]        # Layers to be generated by AI
  deterministic_layers: list[string]# Layers to be rendered by SVG/Sharp
  variations: integer               # Number of candidates

output:
  format: 'png' | 'jpeg' | 'webp'
  quality: 'high' | 'medium' | 'low'
```
